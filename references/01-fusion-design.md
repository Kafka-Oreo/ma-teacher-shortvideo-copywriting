# 马老师短视频文案 · 双大师融合设计

> 目的：把「马老师口播文案」与「老高文案写作」两个已蒸馏 Skill 融合，产出一个专为**马老师短视频文案写作**服务的 Skill。
> 原则：马老师负责"有道理"（投资判断），老高负责"有人看"（叙事包装），语态两者熔合。

---

## 一、为什么需要融合

- **马老师口播文案**：内容扎实、判断严谨（分歧-修复/7日线/量能至上），直播复盘腔，但结构偏"直播流程"（7步），不是短视频的强钩子结构，长度500-2000字偏长。
- **老高文案写作**：强在叙事——钩子工程、可视化主轴、类比引擎、口语对话感，能把复杂讲成好故事，但本身不输出投资判断（需要外部内容）。

**融合的最优解**：马老师的投资逻辑做"判断内核"，老高的叙事结构做"表达外壳"。短视频（150-400字）正好是两者交集的甜区——够短够抓人，又需要真判断。

---

## 二、三塔融合架构

```
马老师投资思维（A塔·内容）
    × 马老师语气DNA（C塔·判断句腔）
    × 老高叙事结构（B塔·钩子/主轴/类比）
    × 老高口语DNA（C塔·推进句腔）
→ 任何一个板块/市场事件/投资主题
→ 高留存短视频口播文案（150-400字）
```

- **A塔·马老师投资思维**：5心智模型 + 8决策启发式 + 高频术语 → 解决"讲什么、判断对不对"
- **B塔·老高叙事结构**：钩子工程4手法 + 可视化主轴3型 + 六段式 + 类比引擎 → 解决"怎么讲、留不留人"
- **C塔·语言熔合**：马老师判断句腔（对吧/我们说/条件式）+ 老高推进设问腔（你知道吗/自问自答/长短句）→ 解决"听起来像谁"

## 三、关键融合点（本Skill独有的设计）

### 1. 钩子套在判断上（老高钩子 × 马老师结论）
马老师每天盘后有判断（"今天是良性分歧""资金去弱留强"），老高的钩子工程把这些**平淡但正确的结论**，改写成让人停下的开场：
- "市场看着冷清，其实钱没走，是换位置了"（反差认知）
- "为什么一个远在几万公里的会议，能让A股缩成地量？"（悬念提问）

### 2. 主轴承载资金/板块推演（老高主轴 × 马老师分析）
马老师的资金拆解/板块轮动，用老高的可视化主轴变"进度感"：
- 复盘 → 一个交易日的分时 = 市场情绪的一天（时间轴）
- 产业链 → 从上游原材料游到下游终端（空间轴）
- 题材演化 → 利多兑现→资金轮动→新主线（逻辑轴）

### 3. 类比翻译马老师术语（老高类比引擎 × 马老师黑话）
马老师术语（老登/冰点/倒车接人/7日线）对普通观众是门槛，用老高类比引擎"翻译"成桌面级日常：
- 老登 → "守旧的老牌大公司"
- 冰点 → "市场的体温计熄火了"
- 倒车接人 → "老司机倒车接你上车"
- 7日线 → "判强弱的那根生命线"

### 4. 单向设问顶替夫妻对话（老高互动位 → 短视频环境）
老高的"夫妻吵嘴"在短视频单人场景还原不了，改用**设问制造互动位**：
- "有人会问，那是不是要跑了？" → "你可能想说，那该不该追？"

### 5. 收束双重兜底（马老师"我们" + 老高"与你有关"）
结尾既不冷也不鸡汤：马老师给"我们"的陪伴/纪律，老高落"这对你的仓位意味着什么"，合起来"别在账单前打光子弹，留点筹码等靴子落地"。

## 四、两种腔调如何不打架（熔合规则）

| 用途 | 用谁的腔 | 例子 |
|------|---------|------|
| 判断句 | 马老师 | "从数据上看，这是良性分歧，对吧" |
| 推进/设问句 | 老高 | "你可能觉得冷清，钱其实换位置了" |
| 观点佐证 | 马老师条件式 | "只要量能补上，修复就大概率成立" |
| 画面/秘闻句 | 老高 | "啪，钱全跑了" |
| 收束 | 双熔合 | "所以别急着打光子弹，对吧" |

**节奏纪律**：一段≤2个"对吧"+≤2个"你知道吗"，避免复读机；避免"综上所述/值得注意的是"书面模板（马老师与老高都反对AI书面味）。

## 六、诚实边界

- 继承的两个源Skill都基于公开/用户提供的一手语料，风格还原≠本人观点
- 财经短视频的**最新数据必须真实核实**，引擎不生成数据
- 无法预测全新市场环境，判断均为条件式推演
