# 🎬 马老师短视频文案引擎（双大师融合版）

**Ma-Teacher Short-Video Copywriting** — 马老师的投资逻辑 × 老高的文案技巧，为投资短视频写作而生的融合 Skill。

> 判断用 **马老师（谈笑间228）** 的投资框架与语气，表达用 **老高（老高与小茉）** 的钩子/主轴/类比叙事骨肉。任何一个板块、市场事件、投资主题，都能写成 3 秒抓人、全程有画面、结尾有回响的短视频口播文案（150–400 字）。

---

## 为什么是"融合版"

| | 马老师口播文案 | 老高文案写作 | **本融合版** |
|---|---|---|---|
| 强项 | 投资判断严谨 | 叙事抓人 | **有判断，又有人看** |
| 内容 | 心智模型+术语 | — | 马老师判断内核 |
| 结构 | 直播复盘流程 | 六段式/钩子/主轴 | 六段式+钩子+主轴（压缩） |
| 长度 | 500–2000 字 | 长口播 | **短视频 150–400 字** |

**三塔架构：**
- **A塔·马老师投资思维** → 想什么、判断对不对（5 心智模型 + 8 决策启发式 + 高频术语）
- **B塔·老高叙事结构** → 怎么讲、留不留人（钩子工程 + 可视化主轴 + 类比引擎 + 六段式）
- **C塔·语言熔合** → 听起来像谁（马老师判断句腔 × 老高推进/设问腔）

---

## ✨ 核心能力

- **钩子工程**：反常识断言/反差认知/悬念提问，开场 3 秒留人
- **可视化主轴**：时间轴/空间轴/逻辑轴，让观众有"进度感"
- **通俗类比引擎**：把"老登/冰点/7日线"翻译成"守旧老牌/体温计/生命线"
- **马老师条件式判断**：所有观点"若…则…"，合规不荐股
- **与你有关收束**：结尾落回"这对你的仓位意味着什么"

## 📄 使用示例

输入一个选题（板块/事件/个股/主题），输出：

2. 3 个钩子候选
3. 正文短视频文案（150–400 字）
4. 类比清单 + 数据来源标注
